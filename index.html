+--------------------------[ ABOUT ]--------------------------+
|                                                             |
|   Dry Fabrications is an independent game studio formed     |
|   in 2021. We started out as a software development         |
|   studio and have since shifted our focus toward making     |
|   games.                                                    |
|                                                             |
|   Over the years we've built a number of projects and       |
|   prototypes, each one teaching us something about how we   |
|   want to make games: tight systems, new worlds, and a      |
|   focus on gameplay that feels great while respecting       |
|   the player's time.                                        |
|                                                             |
|   We're currently heads-down on our latest project,         |
|   working under the name "SWAT: Guardian".                  |
|                                                             |
|   We make the games that we want to play.                   |
|                                                             |
+-------------------------------------------------------------+

+------------------------[ PROJECTS ]-------------------------+
|                                                             |
|   > SWAT: GUARDIAN                        (in development)  |
|                                                             |
|   A cooperative 3D top-down twin-stick shooter. Drop        |
|   into a squad of 4-8, fight relentless hordes of           |
|   zombies, and complete objectives across partially         |
|   randomized maps.                                          |
|                                                             |
|   - Co-op survival for 4-8 players.                         |
|   - Distinct classes with their own abilities, talent       |
|     trees, and team roles.                                  |
|   - Persistent characters and loot with rarities and        |
|     random modifiers.                                       |
|   - Objective-driven missions on modular, procedurally      |
|     assembled maps.                                         |
|                                                             |
